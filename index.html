03 / APPLY IT

Two class paths

A · JINXI

Scene → palette → interaction

Start with your own dated field photograph. Compare a restrained palette and a more expressive version, then explain which changes help viewers read the scene. Preserve the original and record conditions.

B · WATER & MOUNTAIN

Source → scale → claim

Pair a documented observation with an appropriate view: Sentinel or Landsat imagery, building footprints, or weather context. State place, date, spatial scale, uncertainty, and what the visual evidence supports.
